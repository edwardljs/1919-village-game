# 1919: 그날의 마을

어린이를 위한 3D 역사 어드벤처의 첫 번째 플레이 가능한 마일스톤입니다.

## 실행

```bash
npm install
npm run dev
```

표시된 로컬 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 만듭니다.

## 웹 배포

`main` 브랜치에 변경 사항이 올라오면 GitHub Actions가 게임을 빌드해 GitHub Pages에 자동 배포합니다.

- 공개 게임: https://edwardljs.github.io/1919-village-game/
- 소스 저장소: https://github.com/edwardljs/1919-village-game

## 조작

- WASD: 이동
- 마우스: 시점 회전
- Space: 점프
- Shift: 달리기
- E: 대화/줍기
- F3: 상태 정보
